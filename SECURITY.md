# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| >= 0.5  | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in OpenFishTools Studio, please do not disclose it publicly.

Instead, please send an email to:
**cutefishaep@gmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Clear reproduction steps or proof-of-concept code.
- Any suggested mitigations.

We will acknowledge receipt within 48 hours and work to release a patch promptly.
