OpenFishTools

v0.4.8
Active Development Stage (Alpha)

OpenFishTools Studio is a browser-based motion graphics and video editor. Rendering calculations and project storage run entirely locally on your device.

Release Notes
CHANGELOG.md
v0.4.8 Latest Sep 11, 2026
Added
Offline Frame-by-Frame Export Engine New FishExport-Enggine.js — deterministic render loop (t = i/fps). Zero dropped frames regardless of effect complexity or GPU load.
Fixed
Choppy / Patchy Export Output Eliminated wall-clock timestamp dependency. Render speed no longer affects output FPS or smoothness.
v0.4.7 Sep 11, 2026
Added
Export Format Switch (MP4 / WebM) Added format switch to export modal with browser auto-detection for instant 0-second WebM export on Firefox.
Fixed
WebCodecs Active Probe & FFmpeg Transcoding Fixed DOMException on Firefox/Hackintosh AMD and VP8→MP4 codec compatibility errors.
v0.4.6 Sep 10, 2026
Fixed
Null Expression Beat Marker Scoping Resolved stacked null layers losing beat markers outside adjacent null duration windows.
Improved
Timeline Parent-Child Link Connectors Restructured hierarchy connector lines to match After Effects 1:1 with non-overlapping channels and smooth curves.
Fixed
Motion Blur on Null-Driven Layers Enabled velocity detection and sub-frame multi-sampling for layers animated via parent expressions.
Added
Timeline Empty State Added centered 'Drop media here to import' placeholder with interactive dragover highlight.
v0.4.5 Sep 10, 2026
Added
OpenFishTools Warp Presets Added Preset section under Beat Effects featuring one-click multi-layer adjustment presets (WARP1, WARP2, WARP3).
Fixed
Timeline Playhead Synchronization Resolved playhead drift during background cache renders; frame-snapped preset placement precisely to the current playhead frame.
Fixed
Wave Warp Effect Rendering Enhanced Wave Warp canvas shader to support smooth-noise synthesis, directional angle rotation, and seamless edge tiling.
v0.4.4 Sep 10, 2026
Fixed
Debug Panel Relocation Moved Debug / Layer Inspector from Composition Settings header to OpenFishTools settings panel.
Fixed
IndexedDB Storage Calculation Accurate project database storage calculation including raw binary media blobs and frame render cache.
Fixed
Template Editor Layout Pinned media replacement dock to the top on desktop and enlarged touch-friendly cards on mobile.
Fixed
UI Scrollbar Visibility Removed forced scrollbar hiding; enabled clean, theme-matched slim scrollbars across all scrollable lists.
Added
OFTS Export Progress Modal Real-time export progress indicator with DEFLATE Level 9 compression for fast and lightweight .ofts project files.
Added
FSMB Effect & Playback Popover Fish Motion Blur velocity-based frame blending and long-press Play menu with Loop, Speed, and Cache controls.
Improved
Welcome Notice Refinement Clean, objective presentation with complete transparency regarding the active Alpha development phase.
v0.4.3 Sep 08, 2026
Fixed
Multi-layer Keyframe Shift Synchronized keyframe shifting when adjusting multi-layer duration in the timeline.
Fixed
Expression Persistence Ensured layer expression scripts persist intact across project serialization and undo/redo states.
Improved
Preview RAM Cache Optimization Dynamic frame memory management and cache clamping for smoother 60 FPS playback.
v0.4.2 Sep 05, 2026
Fixed
OFTS Memory Crash Prevention Sanitizes canvas buffers, frame caches, and blob URLs before exporting large projects to prevent browser tab crashes.
Improved
Runtime Memory Sanitization Periodic garbage collection of canvas buffer references during editor page navigation.
v0.4.1 Sep 02, 2026
Added
Multi-layer Selection & Drag Select and drag multiple layers simultaneously across the timeline.
Added
Null Object & Layer Parenting Hierarchical transform parenting between layers and null object controllers.
Added
Group Masking (Alight Motion style) Mask and Exclude group creation with destination-in and destination-out blend modes.
Fixed
Audio Scrubbing Glitch Eliminated audio noise artifacts during rapid timeline playhead scrubbing.
v0.3.0 Aug 25, 2026
Added
Modular Layer Effects Registry Extensible modular JavaScript layer effects plugin architecture under effects/.
Added
Interactive Graph Curve Editor Interactive bezier curve editor with control nodes, tangent lines, and timing presets.
Improved
Matcha Theme Standardization Standardized color tokens from css/theme.css and 100% Cal Sans typography.
v0.2.0 Aug 15, 2026
Added
Motion Blur Engine & Text Layers Integrated motion blur calculation, typography text layer editor, and vector shape library.
Added
Responsive Splitter Handle Vertical pill drag handle for fluid dynamic timeline pane resizing on desktop and tablet.
v0.1.0 Aug 01, 2026
Added
First Public Release Initial launch of OpenFishTools Studio, multi-layer timeline, and native .ofts project format.
